# Synora — Project Milestones

This file is not a changelog.

It is the architectural timeline of Synora as a platform: major capability shifts, the reasoning behind them, and the evolution path we can point to years later.

## Policy

- Create a milestone when a change alters platform capabilities (structure, routing, governance, security model, operational primitives).
- Skip milestones for purely cosmetic tweaks or small isolated fixes.
- A milestone should answer: **what changed**, **why it exists**, **what it unlocks**, and **what becomes the new default**.

## Release Milestone — Global Foundation (v1.0) — 2026-07-08

Synora now operates on a native multilingual architecture with structured i18n (PT/ES/EN), language-specific canonical URLs, permanent HTTP redirects (308) for legacy routes, and international SEO primitives (`hreflang` + `canonical`).

This establishes a single codebase prepared for global expansion without requiring future URL or architecture rewrites.
